Рефакторинг модуля фитнес-трекера на Go с применением структур, эмбеддинга и интерфейсов. Реализована архитектура из 5 пакетов: расчёт калорий/скорости (spentenergy), данные пользователя (personaldata), логика тренировок (trainings) и прогулок (daysteps), а также универсальный интерфейс DataParser с функцией Info() для полиморфной обработки разных типов активностей. Код разбит по слоям, данные инкапсулированы в структуры.
